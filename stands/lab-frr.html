Бриф практики

сова Агата — теперь про алгоритмы Дейкстры · бриф практики

Сеть подросла до шести маршрутизаторов, ручные маршруты уже никто не успевает поддерживать. Пора включить голову маршрутизаторам: пусть обмениваются маршрутами сами. На ALT для этого есть FR Routing — набор демонов с интерфейсом vtysh, который мигрировавшие с Cisco инженеры осваивают за вечер. Вы поднимете OSPF как основной протокол и посмотрите RIP и EIGRP на демо-топологии.

Теория

опорный конспект

01 Зачем протоколы маршрутизации

Динамический протокол сам обнаруживает соседей, раздаёт префиксы и перестраивает маршруты при обрыве. RIP — простой и устаревший (хопы до 15), OSPF — стандарт компаний (зоны, метрики по пропускной способности), EIGRP — протокол Cisco, во FRR поддерживается совместимая реализация.

02 OSPF за 10 минут

Все роутеры одной зоны (area 0 — магистраль) обмениваются объявлениями о сетях, строят единый граф и считают кратчайшие пути. Минимальная настройка: router-id, включение протокола на интерфейсах через network или ip ospf area.

# apt-get install frr
# systemctl enable --now frr
# vtysh
R1# configure terminal
R1(config)# router ospf
R1(config-router)# router-id 1.1.1.1
R1(config-router)# network 10.0.1.0/24 area 0
R1(config-router)# network 192.168.10.0/24 area 0
R1# show ip ospf neighbor
R1# show ip route ospf

03 RIP и EIGRP в той же оболочке

vtysh повторяет логику IOS: режимы, контекст router, show-команды. Сравните синтаксис построчно — и вы больше не будете бояться чужого CLI.

router rip
 version 2
 network 10.0.0.0
 no shutdown
!
router eigrp 100
 address-family ipv4 unicast
  network 10.0.0.0
  autonomous-system 100

Бэклог задач

чек-лист
  1. Установите FRR на три ALT-машины (или контейнера), включите демон и проверьте vtysh
  2. Настройте IP-план топологии из трёх роутеров и двух ЛВС (используйте наработки статики)
  3. Поднимите OSPF area 0 на всех интерфейсах, задайте router-id в формате X.X.X.X
  4. Добейтесь состояния соседства Full: show ip ospf neighbor на каждом узле
  5. Проверьте, что маршруты ЛВС появились автоматически: show ip route ospf и сквозной ping
  6. Проведите аварию: погасите интерфейс между R1 и R2, зафиксируйте перестроение маршрута и время
  7. На демо-топологии поднимите RIP v2, сравните таймеры и метрики с OSPF по show-командам
  8. Включите EIGRP AS 100 на двух узлах, выгрузите конфигурацию и сделайте вывод о сходстве CLI с Cisco

Задача считается выполненной после реальной работы на оборудовании, в эмуляторе или на виртуальной машине. В интерактиве чек-лист сохраняет прогресс.

Ситуационная задача

Ситуационная задача. Групповой мозговой штурм: после замены маршрутизатора OSPF-соседство не поднимается, интерфейсы пингуются. Предложите не менее пяти причин (area mismatch, router-id дубль, пассивный интерфейс, firewall, таймеры/MTU, сеть не объявлена) и распределите проверки между участниками группы.

Проверь себя

контрольный тест
Вопрос 1. Что такое area 0 в OSPF?
  • Нулевая зона без маршрутов
  • Магистральная зона, через которую связаны остальные верно
  • Зона для RIP
  • Служебный VLAN

Ответ: Магистральная зона, через которую связаны остальные

Area 0 — магистраль OSPF, все прочие зоны примыкают к ней.

Вопрос 2. Какой инструмент ALT даёт CLI в стиле Cisco для FRR?
  • nmtui
  • vtysh верно
  • iptables
  • ethtool

Ответ: vtysh

vtysh — объединённая оболочка демонов FRR с IOS-подобным синтаксисом.

Вопрос 3. Какое состояние OSPF-соседства означает полную синхронизацию?
  • Init
  • 2-Way
  • Full верно
  • Down

Ответ: Full

Full — базы состояния каналов синхронизированы, маршруты обменены.

Вопрос 4. Почему RIP считают устаревшим?
  • Он не работает на Linux
  • Ограничение 15 хопов, медленная сходимость, не учитывает полосу верно
  • Он требует IPv6
  • RIP шифрует трафик

Ответ: Ограничение 15 хопов, медленная сходимость, не учитывает полосу

RIP прост, но масштабируется плохо: метрика — число транзитных узлов.

Вопрос 5. Что происходит с OSPF при обрыве линка?
  • Маршруты исчезают навсегда
  • Протокол распространяет обновление и строит обходной путь верно
  • Нужно вручную переписать network
  • Перезагружаются все роутеры

Ответ: Протокол распространяет обновление и строит обходной путь

В этом смысл динамической маршрутизации: автоматическая реакция на изменения топологии.
