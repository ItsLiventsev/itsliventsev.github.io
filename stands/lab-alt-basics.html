Тот же день, другое крыло офиса. На серверную стойку поставили машину с ALT Сервер. Здесь нет уютного Packet Tracer — только чёрный терминал. Вы настроите имя узла, сеть и службы так, как это делается на настоящем оборудовании, и увидите, что Linux и Cisco говорят по сути об одном, просто разными словами.

Теория

опорный конспект

01 root, обычный пользователь и sudo

root — суперпользователь с неограниченными правами. Постоянно работать под ним опасно: штатная практика — обычный пользователь плюс повышение прав через sudo (на ALT пользователь должен состоять в группе wheel).

[user@alt ~]$ whoami
user
[user@alt ~]$ su -
Password:
[root@alt ~]# usermod -aG wheel user
[root@alt ~]# exit
[user@alt ~]$ sudo ip a

02 Сеть ALT: /etc/net/ifaces

ALT использует пакет etcnet: каждый интерфейс — каталог /etc/net/ifaces/имя, в нём файлы options (BOOTPROTO, ONBOOT) и ipv4address/ipv4route. После правок сеть перезапускается через systemctl.

# mcedit /etc/net/ifaces/eth0/options
BOOTPROTO=static
ONBOOT=yes
# mcedit /etc/net/ifaces/eth0/ipv4address
192.168.10.20/24
# systemctl restart network
# ip -c a show eth0

03 Пакеты и службы

Установка программ — apt-get install, службы управляются systemd. Это прямые аналоги загрузки IOS-образа и команды no shutdown: сервис нужно не только установить, но и включить в автозагрузку.

# apt-get update
# apt-get install openssh-server
# systemctl enable --now sshd
# systemctl status sshd

Бэклог задач

чек-лист
  1. Загрузите ALT (виртуальная машина или Live-образ), войдите под пользователем и откройте терминал
  2. Задайте имя узла alt-srv1 и проверьте его командой hostname
  3. Создайте пользователя netadmin и добавьте его в группу wheel
  4. Настройте eth0 статически: 192.168.10.20/24, шлюз 192.168.10.1 через /etc/net/ifaces
  5. Перезапустите сеть и подтвердите адрес командой ip -c a
  6. Проверьте ping до шлюза 192.168.10.1 и DNS: ping ya.ru (в учебной сети — до DNS преподавателя)
  7. Установите пакет nano (или mc) через apt-get и продемонстрируйте apt-get install
  8. Сфотографируйте/скопируйте вывод ip -br a и содержимое каталога /etc/net/ifaces/eth0

Задача считается выполненной после реальной работы на оборудовании, в эмуляторе или на виртуальной машине. В интерактиве чек-лист сохраняет прогресс.

Проверь себя

контрольный тест
Вопрос 1. Где ALT хранит постоянную конфигурацию интерфейса eth0?
  • /var/log/eth0
  • /etc/net/ifaces/eth0 верно
  • /home/eth0
  • /proc/net/eth0

Ответ: /etc/net/ifaces/eth0

etcnet: каталог /etc/net/ifaces/<интерфейс> с файлами options, ipv4address.

Вопрос 2. Какая команда установит пакет mc?
  • dpkg -i mc
  • apt-get install mc верно
  • rpm --add mc
  • systemctl install mc

Ответ: apt-get install mc

Дистрибутивы ALT используют apt как фронтенд к RPM: apt-get install.

Вопрос 3. Что делает systemctl enable --now sshd?
  • Только запускает службу сейчас
  • Включает автозапуск и сразу запускает верно
  • Перезагружает службу ежедневно
  • Открывает порт 22 в firewall автоматически

Ответ: Включает автозапуск и сразу запускает

enable — автозапуск при загрузке, --now — немедленный старт одной командой.

Вопрос 4. Членство в какой группе на ALT даёт право на sudo?
  • adm
  • sudoers
  • wheel верно
  • netadmin

Ответ: wheel

На ALT права sudo по умолчанию выдаются членам группы wheel.

Вопрос 5. Какой командой увидеть все интерфейсы одной строкой?
  • ifconfig -all
  • ip -br a верно
  • netstat -i brief
  • show interfaces

Ответ: ip -br a

ip -brief address — компактный аналог show ip interface brief.
