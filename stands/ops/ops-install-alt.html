В СетьПолисе коллеги уже настраивали сеть на ALT — лис Итан оставил заметку, что конфигурация интерфейсов лежит в /etc/net/ifaces. Теория

опорный конспект

01 Установка и первая загрузка

Серверная ОС ставится с образа ALT Server. На этапе установки выбираются разметка диска (отдельные разделы /, /home, swap), профиль пакетов и пароль root. После первой загрузки проверяют версию системы и журналы.

# cat /etc/os-release
# uname -a
# journalctl -p err -b | less

02 Имя узла и сеть по etcnet

ALT использует etcnet: постоянная настройка интерфейса — в каталоге /etc/net/ifaces. Временная команда ip addr исчезнет после перезагрузки, поэтому боевой администратор правит файлы и перезапускает службу.

# mcedit /etc/hostname
srv-hq.datapolis.local
# mcedit /etc/net/ifaces/ens19/options
BOOTPROTO=static
ONBOOT=yes
# mcedit /etc/net/ifaces/ens19/ipv4address
10.20.30.11/24
# systemctl restart network

03 Обновления и приёмка

Перед вводу в эксплуатацию систему обновляют и фиксируют результат в чек-листе приёмки. Это первый артефакт сервисного подхода: машина принимается не на слово, а по списку проверок.

# apt-get update && apt-get upgrade -y
# ip -br a ; systemctl --failed

Бэклог задач

чек-лист
  1. Установите ALT Server на ВМ: разметка с отдельным swap, профиль «Сервер»
  2. Задайте имя srv-hq.datapolis.local и подтвердите hostnamectl
  3. Настройте ens19 статически через /etc/net/ifaces (адрес, маска, шлюз, DNS)
  4. Обновите пакеты и убедитесь, что нет упавших служб systemctl --failed
  5. Проверьте доступность шлюза и DNS ping/traceroute, зафиксируйте вывод
  6. Перезагрузите сервер и докажите, что настройки пережили reboot
  7. Оформите чек-лист приёмки: 7 пунктов с фактическими значениями

Задача считается выполненной после реальной работы на оборудовании, в эмуляторе или на виртуальной машине. В интерактиве чек-лист сохраняет прогресс.

Проверь себя

контрольный тест
Вопрос 1. Где ALT хранит постоянную настройку IP-адреса?
  • /var/run/network
  • /etc/net/ifaces верно
  • /home/admin/net
  • /proc/net/ip

Ответ: /etc/net/ifaces

etcnet: каталог /etc/net/ifaces/<интерфейс> с файлами options и ipv4address.

Вопрос 2. Что покажет systemctl --failed?
  • Список обновлений
  • Упавшие юниты systemd верно
  • Все сетевые соединения
  • Таблицу маршрутов

Ответ: Упавшие юниты systemd

Команда фильтрует юниты в состоянии failed — первый шаг приёмки.

Вопрос 3. Почему ip addr add недостаточно для боевого сервера?
  • Команда требует GUI
  • Настройка временная и исчезнет после reboot верно
  • Она не работает на ALT
  • Она меняет только MAC

Ответ: Настройка временная и исчезнет после reboot

ip меняет состояние ядра на лету; постоянная конфигурация — в файлах etcnet.

Вопрос 4. Что является артефактом приёмки сервера?
  • Устная договорённость
  • Чек-лист с фактическими проверками верно
  • Скриншот рабочего стола
  • Пароль root в чате

Ответ: Чек-лист с фактическими проверками

Сервис принимается по документу, а не по словам — это основа эксплуатации.
