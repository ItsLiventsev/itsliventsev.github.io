Бриф практики

ёжик Боря — ответственный за хранилища · бриф практики

Отделу архива нужно общее хранилище, которое переживает перезагрузку и не открыто всем подряд. Вы развернёте NFS на ALT Server, настроите экспорт с ограничением по подсети, смонтируете папку на рабочих станциях через fstab и разберётесь в правах и владельцах. Заодно поймёте, почему фраза «у меня нет доступа» почти никогда не решается командой chmod 777.

Теория

опорный конспект

01 Экспорт NFS на сервере

Каталог публикуется в /etc/exports с указанием клиентской подсети и опций (rw, sync, root_squash). root_squash безопаснее: root клиента не становится root на сервере.

# apt-get install nfs-server
# mkdir -p /srv/archive
# mcedit /etc/exports
/srv/archive 10.20.30.0/24(rw,sync,root_squash)
# exportfs -rav

02 Монтирование на клиенте

Временный монтаж через mount, постоянный — строка в /etc/fstab. После настройки проверяют автоподъём после reboot и права на запись.

# apt-get install nfs-clients
# mcedit /etc/fstab
srv-hq:/srv/archive /mnt/archive nfs defaults,_netdev 0 0
# mount -a && df -h /mnt/archive

03 Права и группы

Доступ строится на владельце, группе и битах прав. Общие папки для отдела логично завязать на доменную группу, а не раздавать права каждому пользователю.

# chown -R root:noc /srv/archive
# chmod -R 2770 /srv/archive   # setgid: новые файлы наследуют группу

Бэклог задач

чек-лист
  1. Установите NFS-сервер, создайте /srv/archive и опубликуйте экспорт для своей подсети
  2. Включите root_squash и объясните, чем он защищает
  3. На клиенте настройте постоянный монтаж через fstab и проверьте после reboot
  4. Создайте группу отдела и настройте setgid-каталог с наследованием группы
  5. Проверьте отказ: пользователь вне группы не должен писать в папку
  6. Сравните NFS и SMB-шару Windows: протоколы, порты, управление правами
  7. Оформите runbook выдачи сетевой папки по заявке

Задача считается выполненной после реальной работы на оборудовании, в эмуляторе или на виртуальной машине. В интерактиве чек-лист сохраняет прогресс.

Проверь себя

контрольный тест
Вопрос 1. Что делает опция root_squash?
  • Удаляет root
  • Отображает root клиента в непривилегированного пользователя на сервере верно
  • Сжимает трафик
  • Отключает аутентификацию

Ответ: Отображает root клиента в непривилегированного пользователя на сервере

Защита от повышения привилегий через NFS-монтирование.

Вопрос 2. Зачем нужен параметр _netdev в fstab?
  • Ускоряет диск
  • Сообщает, что файловая система сетевая и монтируется после сети верно
  • Шифрует трафик
  • Отключает кэш

Ответ: Сообщает, что файловая система сетевая и монтируется после сети

Без него система может попытаться смонтировать шару до поднятия сети.

Вопрос 3. Какой бит заставляет новые файлы наследовать группу каталога?
  • sticky (1xxx)
  • setgid (2xxx) верно
  • suid (4xxx)
  • umask 000

Ответ: setgid (2xxx)

setgid 2770 — стандарт для командных папок.

Вопрос 4. Аналог NFS в мире Windows для файловых шар?
  • FTP
  • SMB (CIFS), порты 445/139 верно
  • HTTP
  • Telnet

Ответ: SMB (CIFS), порты 445/139

Windows делится папками по протоколу SMB.
