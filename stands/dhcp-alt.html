stand / dhcp-alt · ALT Server + ALT Workstation

Конфигурация DHCP-сервера

Легенда. Вы — администратор компании. Новый отдел получает сеть 192.168.10.0/24. Нужно поднять на ALT Server раздачу адресов, а рабочие станции ALT Workstation настроить на автоматическое получение IP. Сетевой принтер должен всегда получать 192.168.10.50.

WAN (NAT, enp0s3) → ALT Server (DHCP+NAT, 192.168.10.1)
  ├─ LAN 192.168.10.0/24 → ALT Workstation 1 (DHCP-клиент)
  ├─ LAN 192.168.10.0/24 → ALT Workstation 2 (статический IP)
  └─ host printer: MAC 00:11:22:33:44:55 → 192.168.10.50

    ситуационные задачи

    Bug report. Пользователи не получают IP, в логах No subnet declaration for enp0s8. Кнопка «загрузить bug-report» подставит сломанный конфиг — найдите и устраните причину.

    Feature request. Принтер с MAC 00:11:22:33:44:55 должен всегда получать 192.168.10.50 (директива host printer { … }).
