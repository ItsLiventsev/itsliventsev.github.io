Что такое DHCP и как клиент получает адрес (DORA)

DHCP (Dynamic Host Configuration Protocol) автоматически выдаёт клиентам IP-адрес, маску, шлюз и DNS. Сервер слушает порт UDP/67, клиент временно работает на UDP/68.

Получение адреса — четыре шага DORA:

  • Discover — клиент broadcast-ом ищет DHCP-сервер;
  • Offer — сервер предлагает свободный адрес из пула;
  • Request — клиент просит именно этот адрес;
  • Acknowledge — сервер подтверждает аренду (lease) и присылает все параметры.

В терминале клиента весь обмен виден командой dhclient -v enp0s8.

Файл dhcpd.conf: структура и что куда вписывать

Конфигурация лежит в /etc/dhcp/dhcpd.conf. Сверху — глобальные параметры, ниже блоки subnet { … } для сетей и host { … } для резервов. Каждая строка-параметр завершается точкой с запятой, блоки обрамляются фигурными скобками.

  • default-lease-time 600; — аренда по умолчанию, секунд;
  • max-lease-time 7200; — максимальная аренда;
  • authoritative; — сервер главный в этой сети, клиенты быстрее обновляют аренду;
  • subnet 192.168.10.0 netmask 255.255.255.0 { … } — объявление подсети, без него служба падает с ошибкой No subnet declaration;
  • range 192.168.10.100 192.168.10.200; — диапазон динамической выдачи;
  • option routers 192.168.10.1; — шлюз по умолчанию для клиентов;
  • option domain-name-servers 8.8.8.8, 1.1.1.1; — DNS-серверы через запятую;
  • host printer { hardware ethernet …; fixed-address …; } — постоянный адрес по MAC.
Резервирование по MAC: почему .50 и почему вне пула

Принтеру нужен неизменный адрес, чтобы рабочие станции не теряли его после перезагрузки. В блоке host printer связываются MAC-адрес (hardware ethernet) и фиксированный IP (fixed-address).

Резерв выносят вне динамического пула: пул у нас .100–.200, поэтому принтер получает 192.168.10.50. Если адрес попадёт в пул, сервер может выдать его и динамически — возникнет конфликт двух устройств с одним IP.

Служба и диагностика: systemctl, journalctl, ip, dhclient

После правки конфига службу перезапускают и проверяют её статус. Лог показывает, на каком интерфейсе сервер слушает и нет ли синтаксических ошибок. Команда ip a показывает адреса интерфейсов, dhclient на клиенте инициирует новый обмен DORA.
