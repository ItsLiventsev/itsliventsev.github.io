Бриф практики

лис Итан — уже с картой сетей · бриф практики

Маленький филиал не нуждается в сложных протоколах: пять подсетей, три маршрутизатора, предсказуемая топология. Статика здесь быстрее, безопаснее и не тратит ресурсы. Но любая забытая сеть — это «там не открывается, у нас всё пингуется». Учимся мыслить таблицей маршрутов целиком, а не одним устройством.

Теория

опорный конспект

01 Анатомия маршрута

Команда ip route сообщает маршрутизатору: «сеть назначения N/маска достижима через следующий узел A (или выходной интерфейс)». Маршрут по умолчанию 0.0.0.0/0 ловит всё, чему нет более точного маршрута — типичная роль граничного роутера.

R1(config)# ip route 192.168.30.0 255.255.255.0 10.0.1.2
R1(config)# ip route 192.168.30.0 255.255.255.0 gi0/1
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.1.2
R1# show ip route static

02 Двунаправленность связи

Ping не пойдёт, пока обратная сеть тоже не знает маршрут до источника. Частая ошибка новичка: настроить маршрут только в одну сторону и искать проблему в кабеле. Правило: для каждой сети каждая пара маршрутизаторов должна знать путь туда и обратно.

03 Когда статика — правильный выбор

Статические маршруты не нагружают CPU, не передают служебный трафик и предсказуемы. Они хороши в маленьких стабильных сетях, на стыках с провайдером и для маршрутов по умолчанию. В большой растущей сети их поддержка становится ручным адом — там появляются динамические протоколы (следующий спринт).

Бэклог задач

чек-лист
  1. Соберите цепочку R1–R2–R3 с пятьми подсетями (две ЛВС + три межроутерных /30)
  2. Составьте на бумаге единую таблицу: сеть, маска, шлюз для каждого маршрутизатора
  3. Настройте адреса на всех интерфейсах и добейтесь ping между соседними роутерами
  4. Пропишите статические маршруты до удалённых ЛВС на каждом маршрутизаторе (туда и обратно)
  5. На R3 настройте маршрут по умолчанию на R2, на R1 — суммарный маршрут до сетей за R2
  6. Проверьте сквозной ping между ПК обеих ЛВС и traceroute с промежуточными хопами
  7. Удалите один маршрут и зафиксируйте, как меняется show ip route и поведение ping
  8. Проверьте работу напарника: внесите в его схему «слепую зону» и обменяйтесь диагностикой

Задача считается выполненной после реальной работы на оборудовании, в эмуляторе или на виртуальной машине. В интерактиве чек-лист сохраняет прогресс.

Ситуационная задача

Ситуационная задача. Кейс «ТехноСервис»: филиал жалуется — внутренние ресурсы открываются, Интернет не работает. На граничном маршрутизаторе 12 статических маршрутов, маршрута по умолчанию нет, а один из маршрутов указывает next-hop на выключенный интерфейс. Найдите обе проблемы и исправьте.

Проверь себя

контрольный тест
Вопрос 1. Что означает запись ip route 0.0.0.0 0.0.0.0 10.0.1.1?
  • Запрет любого трафика
  • Маршрут по умолчанию через 10.0.1.1 верно
  • Маршрут до сети нулей
  • Очистка таблицы

Ответ: Маршрут по умолчанию через 10.0.1.1

0.0.0.0/0 — дефолт, ловит весь трафик без более точного совпадения.

Вопрос 2. Ping не идёт в одну сторону, обратный маршрут отсутствует. Что увидит отправитель?
  • Ответ от чужого шлюза
  • Таймаут: запросы уходят, ответы не возвращаются верно
  • Немедленный успех
  • Смена MAC-адреса

Ответ: Таймаут: запросы уходят, ответы не возвращаются

Без обратного маршрута echo reply не доходит — ping висит до таймаута.

Вопрос 3. В чём преимущество статики перед динамическим протоколом в маленькой сети?
  • Нет преимуществ
  • Нет служебного трафика, предсказуемость, минимум нагрузки верно
  • Автоматическое обнаружение соседей
  • Статика сама чинит петли

Ответ: Нет служебного трафика, предсказуемость, минимум нагрузки

Статика молчит, детерминирована и не зависит от смежных устройств.

Вопрос 4. Чем запись через next-hop отличается от записи через интерфейс?
  • Ничем после загрузки
  • Next-hop точнее на Ethernet: роутер знает, у кого запрашивать MAC верно
  • Интерфейс работает только на серийных линках
  • Next-hop не сохраняется

Ответ: Next-hop точнее на Ethernet: роутер знает, у кого запрашивать MAC

На broadcast-сетях next-hop корректнее: для интерфейса роутер ищет MAC назначения напрямую.

Вопрос 5. Какой командой увидеть только статические маршруты?
  • show ip static
  • show ip route static верно
  • show routes static
  • display ip route-static

Ответ: show ip route static

show ip route static фильтрует таблицу по типу записи.
