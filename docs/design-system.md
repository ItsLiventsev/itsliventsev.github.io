# Дизайн-система — краткая справка

Полное описание: **[`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md)**. Движение интерфейса —
[`motion.md`](motion.md). Здесь только карта слоёв и правила, которые нельзя нарушать:
все числа сверены с `assets/tokens.css` и проверяются в `scripts/regression-static.js`.

Слои и точки входа:

| Файл | Что внутри |
|---|---|
| `assets/tokens.css` | единственный источник значений: гарнитуры (Literata, Golos Text, Golos Display, JetBrains Mono), палитра, кегли 11–52, шкала отступов 4–80 с шагом 4, радиусы 4/10/14/22/28/pill, три тени, сетка (`--u-max` 1280, рельс 236, шапка 64, таббар 60), тайминги 120/200/320 |
| `assets/base.css` | хром: шапка-мачта, меню-шторка, таббар, поиск-диалог, крошки, оглавление, подвал; формы, кнопки, таблицы, `[hidden]`, scroll-reveal |
| `assets/pages.css` | §1–18: главная, лента активности, профиль, каталоги, редакция, статические страницы, адаптив, компоненты публикаций, кейсы, документы, вселенные, типографика, справка, база знаний |
| `assets/course.css` | учебные вселенные слоя стендов: `[data-ws-*]`, `.ops-*`, `.office-*`, `.lab-*`, `.st-*`, старые компоненты (`.st-lede`, `.lab-panel`, `.sprint-*`) |
| `assets/shell.js` | единственный построитель хрома: шапка, меню, поиск, оглавление с подсветкой через `IntersectionObserver`, тема, «наверх», scroll-reveal (`.ui-reveal` → `.is-revealed`) |
| `assets/catalog.js` | каталоги: поиск, чипы, статус, заглушка — один контракт на «Проекты», «Статьи», «Заметки» |
| `assets/knowledge.js` | граф связей: физика, подсветка окружения, фильтр по рубрике и стендам |
| `assets/feed.js` + `assets/data/activity.json` | журнал изменений: снимок истории GitHub, собирается `scripts/build-activity.js` |

Правила, которые нельзя нарушать:

1. Цвета, размеры и тайминги — только из `tokens.css`. Литералов в компонентах нет.
2. Префикс новых классов — `ui-`; данные — `data-ui-*`. Учебные движки продолжают работать на `data-ws-*`, база знаний — на `data-kn-*` и `data-catalog-*`.
3. Никаких инлайновых стилей. Числовые значения графиков передаются через `data-*`.
4. `!important` допустим только для `[hidden]` и блока `prefers-reduced-motion`.
5. Один акцент — глина `#a8391d`: действие, ссылка, активный пункт, фокус. Второго акцента нет, поэтому рубрики и стенды различаются номером и формой, а не цветом.
6. Один `<main>`, один `<h1>`, `:focus-visible`, `aria-current` только у активного пункта.
