# Дизайн-система itsliventsev · NEO CASUAL 2026

Документ фиксирует систему после 16 волн редизайна. Новые страницы и компоненты
строятся только из этого набора; одноразовые стили запрещены.

### Типографика
Пара: **Unbounded** (500/700/900 — гиганты, заголовки, цифры) × **Golos Text**
(400–700 — тело) + **JetBrains Mono** (коды, штампы, метки). Шкала:
micro .68 / mini .75 / small .875 / **body 1rem** / lead 1.125 / title 1.15rem.
Интерлиньяж: текст 1.6, чтение 1.75, дисплеи 0.96–1.16. Длина строки чтения:
`--prose-measure` 40rem (~78 знаков).

### Пространство, радиусы, тени
Шаг 8px (rem-кратные). Радиусы: 10/12/16px, пилюли 999px. Тени: жёсткая
offset `6px 6px 0` (card) / `4px 4px 0` (кнопки) — фирменный нео-приём.

### Motion
`--dur-fast 120ms / base 220 / slow 380 / slower 600`, `--ease-standard/emphasized/spring/exit`.
Запрещены анимации width/top/left; только композиторные свойства. Вся кинетика —
отклик на скролл (`--sk` прогресс, `--sq` скорость), ambient-анимаций нет.
`prefers-reduced-motion`: движки не стартуют, трансформации гасятся.
Скролл-прогресс: CSS `animation-timeline: scroll()` при поддержке, иначе JS.

### Слои (z-index)
0 фон-декор → 10 контент-акценты → 30 тултипы → 49/50 дропдауны/шапка →
55 док-меню → 60 «наверх» → 100 прогресс → 200 skip/оверлеи. Новые слои —
только из этой шкалы.

## 2. Компоненты (анатомия и состояния)

- **Шапка**: логотип + nav + действия (тема/язык). Fixed на сайте, статичный
  над липким st-topbar на стендах (волна 8). Мобайл ≤720px: nav скрывается.
- **Кнопки** (волна 13, единая система): solid-фон, рамка 2px, жёсткая тень;
  hover = подъём (−2,−2) + тень 6–7px; active = нажатие (+2,+2), тень 0;
  focus-visible = outline 3px верм; disabled = без тени, приглушение.
  Варианты: `.btn-primary` (чернильная, hover верм), `.btn`, `.btn-ghost`,
  `.flat-btn` (юниверсы), `.quick-bubble`, `.filter-btn (.is-active = акцент)`.
- **Карточки**: рамка 2px чернила + жёсткая тень + стикер-радиус; hover-подъём
  −2,−2. Модификаторы: дуотон-тинты (`.light-card/.note-card/.pub-card`),
  штриховка заглушек (`.slot-card`), `.is-active` (акцентная рамка).
- **Чипы/теги**: пилюли, рамка 1.5–2px, hover — тинт-заливка.
- **Формы**: рамка 2px, радиус 10px, focus outline 3px верм, placeholder =
  muted. Кегль наследует 16px (нет iOS-зума).
- **Текстовые блоки**: hero-гигант (Unbounded 900 + ацид-тайник + `--sk`-кинетика),
  `.article-title` (balance), `.zone-title/.p-title` (Unbounded 700), буквицы,
  лид, `.prose-neo` (разделы ▚, маркеры).
- **Служебные**: хлебные крошки, `.nav-bubble` счётчики, теги юниверсов,
  `.title-mark` терминальные маркеры (`>_ # | .`), 404-плакаты.

## 3. Наследуемость страниц

**Общий слой (наследуется всеми):** site.css + shared-chrome.css/js + шрифты +
шапка/подвал + токены. **Шаблоны (5):** главная; список (blog/articles/
archive/projects — hero-gigant + ht-word + маркер + лента карточек);
кейс/статья (esports/navigation/article — prose-measure, дисплейные заголовки);
кабинет стендов (flat-scope + палитра юниверса + общий header + липкий топнав);
служебные (404/faq/sitemap/admin — компактная сетка).

**Пересечения — модификаторы, не копии:** карточка списка vs дуотон-карточка
главной vs uni-card юниверса (палитра через `--card-accent`); кнопки — один
механизм, разные поверхности. **Правило:** страница переопределяет только
акцент (`data-accent`/`--card-accent`) и контент; геометрия и механика — из
общего слоя. Новые страницы стартуют от шаблона, не с нуля.

**Навигация/переходы:** главная → разделы (пузыри + nav) → объект → крошки
назад; стенды всегда имеют общий header (домой) + секционный топнав;
«продолжить с места» для кабинетов.
