# Дизайн-система · SOFT SHELL 2026

Единый UI-слой сайта находится в `assets/soft-shell.css` и подключается последним на всех содержательных HTML-страницах; автономная noindex-страница перенаправления остаётся отдельным исключением. Предшествующие файлы сохраняют конкретную структуру и логику разделов; новый слой отвечает за общую визуальную систему и responsive-полировку. Новые шаблоны должны использовать токены и существующие семантические классы, а не добавлять локальные значения без необходимости.

## Принципы

- **Светлый спокойный интерфейс по умолчанию:** фон `#f5f6f8`, белые поверхности, тонкая рамка, мягкая тень.
- **Сохранение читаемости:** Golos Text для интерфейса и прозы, Source Serif 4 как акцентный дисплейный шрифт, JetBrains Mono — только для кода/технических данных.
- **Модули вместо длинного полотна:** Bento-сетка на главной, аккуратная карточная композиция в каталогах, основная колонка + TOC/метаданные для глубокого чтения.
- **Предсказуемые действия:** тёмная pill-кнопка для первичного действия, нейтральные вторичные действия, пастельные статусные теги.
- **Прогрессивное улучшение:** контент и обычные ссылки работают без JS; глобальный поиск добавляет быстрый путь поверх сайта.
- **Доступность:** семантические заголовки, видимый focus-ring, keyboard-first поиск, reduced-motion, тач-цели и текстовые метки у действий.

## Токены

В `:root` и `:root[data-theme="dark"]` определены парные значения:

| Токен | Светлый режим | Тёмный режим | Назначение |
|---|---|---|---|
| `--bg` | `#f5f6f8` | `#11151b` | фон документа |
| `--surface` | `#ffffff` | `#191f27` | карточки и панели |
| `--surface-2` | `#f0f2f5` | `#202833` | вложенные поверхности/hover |
| `--text` | `#17202c` | `#eef2f7` | основной текст |
| `--text-2` | `#3e4a59` | `#c7d0dc` | вторичный текст |
| `--muted` | `#687585` | `#a0adbc` | подписи и метаданные |
| `--border` | ink 9% | белый 10% | hairline-разделители |
| `--shadow-card` | `0 4px 20px rgba(24,35,50,.045)` | `0 4px 20px rgba(0,0,0,.2)` | тихое отделение поверхности |
| `--shadow-hover` | `0 14px 34px rgba(24,35,50,.09)` | `0 14px 34px rgba(0,0,0,.32)` | состояние наведения |
| `--radius` / `--radius-lg` | 20px / 24px | 20px / 24px | карточки, крупные панели |

Акценты разделов могут иметь собственные пастели, но базовые surfaces и контраст текста не меняются. Цвета главной/текста не задаются inline-стилями, если для роли есть токен.

## Композиция и брейкпоинты

- **Desktop ≥1080px:** 12-колоночная Bento-сетка, hero занимает всю ширину; небольшие модули занимают 4 колонки, основные — 8.
- **Tablet 680–1079px:** две колонки, hero и большие редакционные секции — во всю ширину.
- **Mobile <680px:** одна колонка; боковые панели превращаются в поток над содержимым; внутренние отступы уменьшаются до 16–22px.
- **Wiki/reading ≥1024px:** боковая панель около 250px + гибкая колонка текста; TOC закрепляется в пределах viewport. На меньших экранах оглавление переходит над статьёй.
- Внешний контентный максимум остаётся ограниченным, строки чтения — не растягивать на всю ширину монитора.

## Компонентный контракт

- `.site-header`, `.site-nav`, `.nav-link`: общий навигационный хром, активный пункт виден без цветовой зависимости в одиночку.
- `.card`, `.p-card`, `.note-card`, `.pub-card`, `.lab-panel`: мягкая белая поверхность, 1px hairline, радиус 20px; интерактивная карточка поднимается на 2–3px.
- `.btn-primary` / `.flat-btn`: заполненная pill-кнопка для главного действия. Вторичные действия — тихие контурные/нейтральные.
- `.crumbs` / `.st-crumbs`: компактная иерархическая навигация; не заменять на одну кнопку «назад».
- `.wiki-layout` / `.wiki-nav`: поиск и структурированные категории слева на больших экранах, естественный порядок на мобильном.
- `.toc-link`: TOC рядом с длинным текстом, активная глава отделяется мягкой поверхностью.
- `.site-search-dialog`: общая палитра глобального поиска с локальным индексом; открывается кнопкой, `⌘K`, `Ctrl+K` или `/`; не требует стороннего сервиса.
- Статусы и бейджи — короткие, пастельные; иконка никогда не заменяет доступное имя.

## Архитектура, темы и изменение

`soft-shell.css` подключён последним после page-specific CSS и Tailwind fallback. Это намеренно единый слой; не копировать его правила по отдельным страницам. Для нового компонента:

1. Использовать существующий токен и семантический класс.
2. Для нового глобального паттерна добавить один компонент в `soft-shell.css` и покрыть его регрессионным тестом.
3. Если интерактивен — добавить клавиатурное поведение и `:focus-visible`; проверить `prefers-reduced-motion`.
4. Если появляется контентная страница — добавить её в `assets/search-index.json` запуском `python3 scripts/build-search-index.py`.
5. Запустить `node scripts/regression-static.js` и `python3 scripts/audit-html.py`.

Стенды и учебные пространства используют те же общие поверхности и тему, но их задания, идентификаторы, состояние и механика остаются в собственных доменных движках (`stands.js`, `ops-*`, `office-*`). Редизайн не меняет хранение прогресса в браузере.
