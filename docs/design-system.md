# Дизайн-система — краткая справка

Полное описание: **[`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md)**.

Слои и точки входа:

| Файл | Что внутри |
|---|---|
| `assets/tokens.css` | цвета, шрифты, шкала 11–62, шаг 4 px, радиусы 8/16/24, тени, рельс 244 px |
| `assets/base.css` | оболочка (мачта, меню, таббар, поиск, крошки, оглавление, подвал), формы, кнопки, таблицы |
| `assets/pages.css` | главная, каталоги, редакционные страницы, статические страницы, кейсы, лента |
| `assets/course.css` | учебные вселенные: `[data-ws-*]`, `.ops-*`, `.office-*`, `.lab-*`, `.st-*` |
| `assets/shell.js` | единственный построитель хрома: шапка, меню, поиск, оглавление, тема, «наверх» |

Правила, которые нельзя нарушать:

1. Цвета и размеры — только из `tokens.css`. Литералов в компонентах нет.
2. Префикс новых классов — `ui-`; данные — `data-ui-*`. Учебные движки продолжают работать на `data-ws-*`.
3. Никаких инлайновых стилей. Числовые значения графиков передаются через `data-*`.
4. `!important` допустим только для `[hidden]`.
5. Один `<main>`, один `<h1>`, `:focus-visible`, `aria-current` только у активного пункта.
