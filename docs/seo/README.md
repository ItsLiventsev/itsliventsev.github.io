# SEO-раздел: что где лежит

| Файл | Назначение |
| --- | --- |
| `audit-2026-11-04.md` | полный аудит: метод, итог, карта, тикеты, приоритеты |
| `page-map.csv` | построчная карта 140 маршрутов (генерируется, не править руками) |
| `structured-data-templates.md` | готовые JSON-LD: Person, BlogPosting, LearningResource, Quiz, DefinedTermSet |
| `measurement.md` | контрольные запросы, операторы, протокол замеров, формат отчёта |
| `writer-backlog.md` | 10 брифов для агента-писателя + критерии приёмки |

## Пересобрать карту

```bash
python3 scripts/seo-audit.py          # сводка + page-map.csv
python3 scripts/seo-audit.py --quiet  # только CSV (для CI)
```

Скрипт только читает HTML, ничего не меняет. Шесть чисел, за которыми стоит следить
(см. `measurement.md`, §7): индексируемые маршруты, сироты, «тонкие» страницы,
длины title/description, битый JSON-LD, страницы вне sitemap.

## Отношение к существующей документации

`docs/seo.md` описывает конвейер сборки (что делает `build-seo.js`) — он остаётся
актуальным, кроме двух устаревших мест: «Tailwind CDN» (в коде его нет) и ссылка на
несуществующий `scripts/seo-test.js`. Правим их в рамках T-17, а не дублируем здесь.
