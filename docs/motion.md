# Motion contract · Workspace UI

Workspace — интерфейс рабочей среды, а не showcase-анимация. Движение помогает показать состояние и не должно отвлекать от задания или чтения.

## Токены

Токены объявлены в `assets/workspace-tokens.css`:

- `--ws-motion`: 160ms, стандартный переход hover/focus/press;
- drawer: 220ms, только `transform`;
- `prefers-reduced-motion: reduce`: переходы выключаются, плавный scroll отключается.

## Разрешённые реакции

- Карточка: изменение border/shadow; лёгкий подъём не более 2px.
- Кнопка: короткий переход цвета и небольшой press-scale.
- Drawer: вход/выход через `translateX`, overlay через opacity.
- Диалог поиска: системный dialog без блокировки навигации с клавиатуры.

Не использовать параллакс, бесконечный ambient, скролл-искажения, прыгающие бейджи и анимацию, из-за которой контент появляется только после IntersectionObserver. Учебные таймеры, прогресс и игровые состояния относятся к бизнес-логике модулей и не подменяются визуальными эффектами.

## Ручная проверка

1. Клавиатурой откройте поиск (`Ctrl/⌘K`), найдите запись, закройте Escape.
2. На узком экране откройте drawer, проверьте overlay, Escape, ссылку и блокировку фонового скролла.
3. Переключите светлую/тёмную тему и проверьте контраст форм и статусов.
4. Включите системный reduced motion: все страницы и задания должны оставаться видимыми и доступными.
