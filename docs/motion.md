# Движение интерфейса

Токены времени — в `assets/tokens.css`, правила — в `assets/base.css` и `assets/pages.css`.
Ни одной анимации вне этого списка: если появляется новое число, сначала токен, потом правило.

| Что | Длительность | Свойства |
|---|---:|---|
| hover / focus / press | `--u-dur-1` = 120 ms | `color`, `background`, `border-color` |
| сдвиг и раскрытие панелей, подъём карточек | `--u-dur-2` = 200 ms | `transform`, `opacity` |
| шторка меню, смена темы | `--u-dur-3` = 320 ms | `transform`, `visibility` |
| открытие поиска (`dialog` + подложка) | 190 ms, литерал в `base.css` | `opacity`, `transform` |
| scroll-reveal секций | 520 ms, литерал в `base.css` | только `transform` |
| график ленты активности | 340 ms + 24 ms на шаг | `transform`, `opacity` (WAAPI в `feed.js`) |
| счётчики на главной | 700 ms | число, без анимации раскладки |
| лента итераций: бегущая строка до JS | 16 s на круг, литерал в `pages.css` | только `transform` (`translateY(-50%)`) |
| лента итераций: живой шаг | 0,7–1,5 с, темп задаёт `assets/iter-strip.js` | новые строки: `opacity`, `transform`; прогресс — `transform: scaleX` |
| лента итераций: пульс и кольцо | 1.6 s и 1.8 s | `opacity`, `transform` |

Почему три числа живут вне токенов, а не в них:

- **190 ms** у поиска — `dialog` и `::backdrop` должны раскрыться одновременно; общий токен
  привязал бы их к панелям и сделал окно медленнее, чем вызывающий его клик.
- **520 ms** у scroll-reveal — это не переход состояния, а появление блока при прокрутке;
  к нему не применяется правило «быстро, как отклик на действие».
- **340 ms + 24 ms шаг** и **700 ms** — счётные анимации (`feed.js`, `shell.js`), их темп
  задаётся кодом, а не CSS-переходами.

Правила:

- Анимируются только `transform` и `opacity`; раскладка не пересчитывается.
- Scroll-reveal двигает блок на 14 px и **не меняет прозрачность**: контраст и замеры axe
  не зависят от того, успел ли сработать `IntersectionObserver`.
- Явно помеченных `data-ui-reveal` блоков — не больше трёх на страницу, автоматических — до 12.
- Карточки не «поднимаются» бесконечно: подъём на 2 px только по hover и focus.
- `prefers-reduced-motion: reduce` отключает появление, переходы панелей, плавную прокрутку
  и анимацию графика целиком — не «ускоряет», а убирает.
- Лента итераций на главной переключается из CSS в JS: пока `assets/iter-strip.js` не загрузился,
  строки едут бесконечной лентой, дальше скрипт снимает анимацию (`is-live`), ведёт окно из пяти
  строк, пишет измеренное время шага и счётчики. При `reduce` скрипт выходит до запуска таймеров:
  остаётся статичный список, кнопка паузы скрыта, секундомер стоит на `00:00`.
