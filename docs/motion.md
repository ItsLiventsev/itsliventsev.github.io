# Motion-система и общий хром: стандарты движения и ручные проверки

Документ фиксирует единый стандарт анимаций для мягкого сайта и трёх
учебных вселенных (СетьПолис, ОфисПолис, ДатаПолис). Регрессии ловит
`scripts/regression-static.js` (секция 21), здесь — как система устроена
и что проверять руками.

## 1. Токены движения

Объявлены в `assets/site.css` (`:root`), в `assets/stands.css`
продублированы алиасами с префиксом `--st-`.

| Токен | Значение | Где применять |
| --- | --- | --- |
| `--dur-fast` | 120ms | hover, focus, active, тень прилипающей шапки |
| `--dur-base` | 220ms | меню, смена темы, переключатели, аккордеоны |
| `--dur-slow` | 380ms | перестроение сеток, липкие блоки, появление модалок |
| `--dur-slower` | 600ms | reveal секций, skeleton-пульс |
| `--ease-standard` | cubic-bezier(.2,.7,.2,1) | обычные переходы |
| `--ease-emphasized` | cubic-bezier(.2,.8,.2,1) | появление элементов (вход) |
| `--ease-exit` | cubic-bezier(.4,0,1,1) | исчезновение; выход на 30–40% короче входа |

Историческая переменная `--ease` оставлена алиасом `--ease-standard`.
Числовых длительностей в `transition:` быть не должно — харнесс падает
на любом `.2s`-литерале.

## 2. Что можно анимировать

Только композитор-friendly свойства: `transform`, `opacity`, `clip-path`,
`grid-template-rows/columns`. Запрещены переходы `width`, `height`,
`top`, `left`, `right`, `bottom`, `max-height`.

- Прогресс-бары (`xp-bar`, `quest-progress`, `lab-progress`, `lg-bar-fill`,
  полоса чтения) живут на `transform: scaleX(var(--p))`; значение `--p`
  (0…1) выставляют JS-шаблоны и `setProperty`, инлайнового `style.width` нет.
- Аккордеон (`details.accordion` в `archive.html`) раскрывается через
  `grid-template-rows: 0fr → 1fr` с обёрткой `.acc-inner`; закрытие
  доигрывает `shared-chrome.js` классом `.is-closing`.
- Мобильное меню мягкого сайта — `position: fixed` оверлей на
  `translateY + opacity`, шапка не меняет высоту, контент не сдвигается.
- Липкий профиль на мобиле схлопывается в «пилюлю» через
  `grid-template-rows: 0fr` (обёртки `.id-collapse`).

## 3. Геометрия шапки

Высоты зафиксированы токенами, чтобы исключить CLS:

- `--header-h-lg: 4rem` (десктоп), `--header-h-md: 3.75rem` (≤880px),
  `--header-h-sm: 3.25rem` (≤480px);
- шапка стендов на мобильном — две строки, `--st-topbar-h-mobile: 5.25rem`;
- `st-topnav` ни на одном брейкпоинте не переносит пункты: `nowrap`
  и горизонтальный скролл, скроллбар скрыт;
- хлебные крошки резервируют `min-height: 1.75rem`.

## 4. Общий хром

`assets/shared-chrome.css` и `assets/shared-chrome.js` подключаются на всех
69 страницах последними (после scope-стилей). Внутри: View Transitions
имена `chrome-brand`, `chrome-theme`, `page-title`; единые `skip-link`,
`theme-toggle`, `noscript-bar`, геометрия футеров; skeleton; табы секции
«стек»; тосты; тень `.st-topbar.is-scrolled`; компактный профиль;
плавные якоря с потолком 400ms.

## 5. prefers-reduced-motion

Глобальный сброс в `site.css` обнуляет длительности анимаций/переходов
до .01ms и выключает плавный скролл. Дополнительно: `reveal`/`stagger`
показываются сразу, ambient и party-mode не запускаются, skeleton не
пульсирует, View Transitions отключаются, аккордеон и якоря переключаются
мгновенно. Информация не теряется ни в одном состоянии.

## 5.1. Flow-motion слой 2026 (`flow.css` / `flow.js`)

Подключается последним на всех страницах. Эстетика Apple HIG / One UI:
элементы не «падают», а выезжают из-под маски по мягкой пружине, контент
наследует переменные движения по уровням DOM.

Дополнительные токены: `--ease-spring` (лёгкий овершут), `--flow-rise(-sm)`,
`--flow-blur(-sm)`, `--flow-glass` (стекло панелей), `--flow-dur`,
`--flow-step` (шаг стаггера 56ms, потолок 6 элементов).

- **Вход блоков** — `[data-flow]`: `rise` (по умолчанию), `blur` (с размытием),
  `pop` (scale .96), `mask` (clip-path для текста). Наблюдатель —
  IntersectionObserver, класс `.flow-in`, страховка 1.6s.
- **Пословный текст** — `[data-flow-words]`: JS безопасно разбивает только
  элементы без вложенных тегов, каждое слово в маске `.flow-word` выезжает
  по `--ease-spring` с задержкой `--i * 46ms` (потолок 8 слов).
- **Меню** — мобильная панель сайта: стекло `backdrop-filter: var(--flow-glass)`,
  масштаб .97→1 от точки бургера, пункты каскадом через `--i`; в стендах
  активный пункт помечается скользящей чертой `::after` на `scaleX`.
- **Динамический контент** — карточки (`sla-stat`, `quest-card`, лента,
  тикеты) играют mount-keyframes `flow-rise/flow-pop`; keyframe `to` не
  содержит `transform`, поэтому hover-эффекты после завершения работают
  поверх, а перерендер JS дашбордов повторяет вход естественно.
- **Ambient** — flow.js инжектит на стенды слой `.st-ambient` с моно-глифами
  (`#`, `/`, `>_`, `*`) разной глубины резкости и двумя баблами; на мягких
  страницах баблы добавляются в существующий `.ambient`. Слой
  `aria-hidden`, `pointer-events: none`, z-index 0.
- **Параллакс** — слой смещается за курсором не более чем на 14px через
  rAF-лерп, только при `pointer: fine`; внутренние keyframe-анимации не
  ломаются, поскольку трансформ стоит на контейнере.
- Reduced-motion: flow.js завершается сразу, CSS принудительно показывает
  все элементы и отключает ambient/модалки/слова.

## 6. Ручной QA-чеклист (перед релизом)

1. **Reduced motion:** включить в ОС, пройти главную, хабы стендов,
   лабораторную — нет движений длиннее 100ms, нет пустых блоков.
2. **Медленная сеть (Slow 3G):** главная и хаб ДатаПолиса не «прыгают»:
   контейнеры `#sla-grid`, `#board`, `#roadmap`, `#feed` зарезервированы.
3. **Ресайз 320 → 1440px:** шапка не меняет высоту рывком; `st-topnav`
   скроллится горизонтально, не переносится; мобильное меню — оверлей.
4. **Клавиатура:** Tab проходит все интерактивные элементы с видимым
   `focus-visible`; мобильное меню и party-mode закрываются по Esc.
5. **Тема:** переключение без вспышки, иконка крутится `--dur-base`
   синхронно с перекраской; на reduced-motion — мгновенно.
6. **Прямые заходы:** `/`, `/stands/ops/index.html`,
   `/stands/office/index.html` — все пути к CSS/JS резолвятся,
   skip-link уводит к `#main-content`, крошки ведут на хаб вселенной.
