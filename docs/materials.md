# Учебные материалы: как устроен раздел

Этот файл — контракт раздела `blog/materials/`. Он объясняет, как добавить тему,
какие поля фронтматтера обязательны, откуда берётся дерево навигации и что
проверяет сборка. Материалы — не заметки: заметка короткая и ссылается на
соседей, материал — полноценная учебная тема с целью, разбором и практикой.

## 1. Источник правды

- `assets/data/knowledge/materials.json` — дерево: разделы, группы, активные темы
  (`items`) и запланированные (`planned`). Здесь же `num`, `title`, `short`, `about`.
- `assets/data/knowledge/materials/*.md` — тела тем: YAML-фронтматтер, затем сразу
  Markdown без литерала `body: |`.
- `blog/materials.html` и `blog/materials/<id>.html` — **генерируются**
  `scripts/build-materials.js`, руками не правятся.

Тема считается опубликованной, если её `id` стоит в `items` группы. Если файла нет —
сборка сообщает об ошибке: страницы-заглушки не создаются намеренно.

## 2. Фронтматтер темы

```yaml
---
title: VLAN и trunk
summary: Один провод — много сетей; тег решает, в какую сеть попадёт кадр.
date: 2026-11-04
updated: 2026-11-04
level: практика      # база | практика | продвинутый
readtime: 9 мин
ai: true
notes: [kn-vlan]     # связанные заметки раздела blog/
sources:
  - title: "IEEE 802.1Q"
    url: https://standards.ieee.org/
    publisher: IEEE
    accessed: 2026-11-04
goal:
  - объяснять, зачем нужен тег;
  - настраивать trunk между коммутаторами.
---
```

Обязательны: `title`, `summary`, `date`, `level`, `readtime`, `ai`, `goal`.
`notes` — ссылки на заметки (`/blog/kn-*.html`), `sources` — внешние источники
с датой обращения. Персональные данные (ФИО, группы, название организации,
учётные данные стендов, отчёты по практике) в материалах не публикуются.

## 3. Разметка внутри темы

- `## Заголовок` — разделы; из них собирается правая навигация и оглавление.
- Таблицы Markdown превращаются в `.kn-table` внутри `.kn-table-wrap`.
- Блок с отступом в четыре пробела или ``` — код в `.kn-code`.
- `[[kn-vlan]]` — ссылка на заметку, `{{vlan-i-trunk}}` — ссылка на другую тему.
  Обе проверяются сборкой: неизвестный id — ошибка.
- `> цитата` — врезка `.kn-def`, поле `goal` — блок `.kn-goal`.

## 4. Сборка и проверки

```bash
node scripts/build-materials.js           # пересобрать дерево и страницы тем
node scripts/build-materials.js --check   # только проверить, без записи
```

`--check` входит в `site-checks`, полная сборка — в `post-index.yml` перед
индексами и SEO. Проверяется: наличие файла для каждого `items`, обязательные
поля, корректность `[[…]]` и `{{…}}`, отсутствие пустых тем и дублей `id`.

## 5. Связанные файлы

- `assets/pages.css` — блок «Учебные материалы»: `.kn-wiki-layout`, `.kn-wiki`,
  `.kn-crumbs`, `.kn-goal`, `.kn-code`, `.kn-mat-*`.
- `docs/notes.md` — контракт заметок (`blog/kn-*.html`), на которые ссылаются темы.
- `blog/graph.html` — заглушка-редирект: графа связей на сайте больше нет.
