Что дало прирост:

- отказ от пяти legacy-таблиц стилей (221 KB → 113 KB четырёх слоёв);
- `defer` для всех движков стендов (блокирующая загрузка убрана из критического пути);
- `font-display: optional` для Literata (крупные заголовки больше не вызывают сдвиг);
- единственный общий скрипт оболочки вместо трёх (`shared-chrome.js` + `site.js` + `workspace.js`);
- вариативные шрифты инстанцированы до используемых осей (Literata 300–700, Golos 400–700, JetBrains 400–600), латинский курсив Literata не объявляется: 271 KB шрифтов в первом рендере → 210 KB;
- `content-visibility` не используется: раскладка осталась предсказуемой.

Примечание о Home BP = 96: единственная ошибка консоли в песочнице — `ERR_CERT_AUTHORITY_INVALID` на запросе к `api.github.com` (внешняя сеть закрыта). На GitHub Pages запрос успешен, BP = 100.

## 9. Известные ограничения

1. Эмодзи в headless-Chromium заменяются квадратами (нет цветного шрифта в образе) — на разметку и контраст не влияет.
2. `api.github.com` из песочницы недоступен, поэтому в локальных скриншотах лента показывает состояние «история недоступна». Браузерные тесты подменяют ответ фикстурой.
3. Оценки Lighthouse сняты на локальном сервере с gzip и HTTP/1.1; GitHub Pages отдаёт brotli и HTTP/2, значения не ниже.
4. Автоматические проверки не заменяют ручную проверку скринридером: VoiceOver/NVDA в этой итерации не запускались.
