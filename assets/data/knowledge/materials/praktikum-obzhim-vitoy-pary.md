## Что понадобится

| Инструмент | Зачем |
| --- | --- |
| Кримпер | обжим коннектора |
| Стриппер или нож | снятие оболочки без повреждения жил |
| Коннекторы RJ-45 | по числу концов, плюс запас |
| Тестер кабеля | проверка пар и порядка |
| Кабель UTP Cat5e | заготовка нужной длины |

Расход: на одну попытку — один коннектор, поэтому берут с запасом. Испорченный коннектор не переобжимается.

## Порядок работ

**1. Снять оболочку.** Отступить 2–3 см от конца, надрезать оболочку по кругу и снять. Жилы не надрезать: повреждённая жила даёт плавающий контакт, который проявится через недели.

**2. Распрямить и развести жилы.** Порядок по T568B:

```text
1 бело-оранжевый   2 оранжевый
3 бело-зелёный     4 синий
5 бело-синий       6 зелёный
7 бело-коричневый  8 коричневый
```

**3. Выровнять и подрезать.** Жилы должны быть ровными и одинаковой длины — примерно 12–13 мм, чтобы медные контакты коннектора достали до них, а оболочка попала под защёлку.

**4. Вставить в коннектор.** Коннектор повёрнут защёлкой вниз, жилы идут в свои каналы. Проверить на просвет: все восемь жил должны дойти до торца.

**5. Обжать.** Плавное усилие до щелчка. После обжима подёргать коннектор: он не должен двигаться на кабеле.

**6. Повторить на втором конце** по той же схеме (прямой обжим — одинаковый порядок).

## Проверка

```text
Тестер: 1-2, 3-6, 4-5, 7-8 горят по порядку
```

Диагностика по результату тестера:

| Что видно | Причина |
| --- | --- |
| пара не светится | нет контакта, жила не дошла |
| порядок перепутан | ошибка в разводке |
| светится не в том порядке | перекрёстный обжим вместо прямого |
| светится через одну | повреждена одна жила в паре |

## Проверка на оборудовании

Тестер проверяет электрику, но не подтверждает скорость. Финальная проверка — порт:

```bash
ip link show eth0
ethtool eth0 | grep -E 'Speed|Duplex|Link detected'
```

Ожидаемый вывод для гигабитного линка:

```text
Speed: 1000Mb/s
Duplex: Full
Link detected: yes
```

Если скорость 100 Мбит/с, а кабель Cat5e — почти всегда две жилы не контачат. Причины по частоте: жила не дошла до торца, оболочка не зашла под защёлку, перепутаны местами пары 1–2 и 3–6.

## Ошибки, которые встречаются чаще всего

- **Снимать оболочку на 5 см.** Оголённые жилы у торца — плохой контакт и отсутствие фиксации.
- **Не подрезать жилы ровно.** Одна жила короче — не достаёт.
- **Схема T568A с одной стороны, T568B с другой.** Получается перекрёстный кабель; для современных портов может работать, но в схеме это ошибка.
- **Обжим без проверки тестером.** «Работает» проверяется только тестом.
- **Использовать кабель Cat5 для 1 Гбит/с.** Не заработает на 1000 — только 100 Мбит/с.

## Что сдать по работе

1. Фотографию обоих концов с видимым порядком жил.
2. Результат тестера (все восемь линий по порядку).
3. Вывод `ethtool` с согласованной скоростью.
4. Одну строку вывода о том, как проверялась целостность.

## Итог

- Порядок T568B — одинаковый на обоих концах для прямого обжима.
- Жилы подрезаются ровно, оболочка заходит под защёлку.
- Тестер проверяет электрику, `ethtool` — согласованную скорость.
- 100 Мбит вместо 1000 — почти всегда контакт одной-двух жил.
