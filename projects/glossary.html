DHCP

сети

Dynamic Host Configuration Protocol. Сетевой протокол, позволяющий устройствам автоматически получать IP-адрес, маску подсети, шлюз и параметры DNS при подключении к сети.

аналогия

Как администратор общежития, который при заселении выдает каждому студенту уникальный номер комнаты, чтобы почтальон знал, куда нести письма.

DNS

сети

Domain Name System. Компьютерная распределенная система для получения информации о доменах. Чаще всего используется для сопоставления IP-адресов с читаемыми человеком доменными именами.

аналогия

Телефонная книга: вы ищете имя (домен), а система выдает вам номер телефона (IP-адрес).

VLAN

сети

Virtual Local Area Network. Технология, позволяющая логически разделить один физический коммутатор на несколько независимых широковещательных доменов.

аналогия

Как звукоизолирующие перегородки в опенспейсе: физически все в одной комнате, но функционально разделены и не мешают друг другу.

SSH

ос

Secure Shell. Сетевой протокол прикладного уровня, позволяющий производить удаленное управление операционной системой и туннелирование TCP-соединений с обязательным шифрованием всего трафика.

пример
ssh admin@192.168.1.10 -p 22

Active Directory (AD)

ос

Служба каталогов от Microsoft для сетей Windows. Обеспечивает централизованное управление учетными записями пользователей, компьютеров и применение групповых политик (GPO).

ключевая функция

Единый вход (Single Sign-On): пользователь вводит пароль один раз и получает доступ ко всем разрешенным ресурсам домена.

Контейнеризация

ос

Технология виртуализации на уровне операционной системы, позволяющая запускать изолированные пользовательские пространства (контейнеры) с собственными процессами и сетью, использующие ядро хост-системы (например, Docker).

отличие от ВМ

Виртуальная машина эмулирует целое «железо» и свою ОС. Контейнер делит ядро с хостом, что делает его легковесным и быстрым в запуске.

СУБД

бд

Система Управления Базами Данных. Программное обеспечение, предназначенное для создания, ведения и совместного использования базы данных неопределенным кругом пользователей (например, PostgreSQL, MySQL).

аналогия

Если База Данных — это библиотека с книгами, то СУБД — это библиотекарь, который организует хранение, поиск и выдачу данных.

Первичный ключ (PK)

бд

Primary Key. Поле (или набор полей) в реляционной таблице, которое однозначно идентифицирует каждую запись. Не может содержать пустые (NULL) или повторяющиеся значения.

пример

ID_Сотрудника или номер зачетной книжки студента.

Firewall

безопасность

Межсетевой экран. Программный или аппаратный элемент компьютерной сети, осуществляющий контроль и фильтрацию проходящих через него сетевых пакетов в соответствии с заданными правилами безопасности.

аналогия

Охрана на проходной предприятия, которая проверяет пропуска и решает, кому можно войти, а кому нет.

VPN

безопасность

Virtual Private Network. Технология, позволяющая создать защищенную (зашифрованную) логическую сеть поверх публичной или ненадежной сети (например, Интернета).

применение

Безопасный удаленный доступ сотрудника к внутренним ресурсам компании из дома.
