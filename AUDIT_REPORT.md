# Аудит сайта itsliventsev.github.io → v12 «Мастерская»

Дата: 2 ноября 2026. Ветка `arena/e7d528cd-itsliventsev-github-io` → `main`.
Объём: 76 HTML-страниц (75 публичных + офлайн-фолбэк), 52 учебных маршрута в `stands/`.

Документ фиксирует, что было сломано до переработки, что сделано сейчас и почему.
Проектные решения — в `DESIGN_SYSTEM.md`, проверки — в `QA_REPORT.md`, источники — в `REFERENCES.md`.

---

## 1. Метод

1. Инвентаризация всех маршрутов: тип страницы, шаблон, компоненты, DOM-хуки, зависимости.
2. Статический аудит: `python3 scripts/audit-html.py` (структура, дубли `id`, `h1`, битые ссылки), `grep` по токенам, `!important`, inline-стилям и мёртвым ассетам.
3. Браузерный аудит: Playwright + Chromium, ширины 360 / 768 / 1024 / 1440, консольные ошибки, горизонтальная прокрутка, размеры целей.
4. Доступность: axe-core, WCAG 2.1 AA (19 страниц × 2 темы), плюс Lighthouse a11y.
5. Производительность: Lighthouse 12 (mobile-эмуляция по умолчанию) против статического сервера с gzip — так же, как отдаёт GitHub Pages.

## 3. Что было сломано

### 3.1 Семантика и доступность
- Два уровня шапки: собственный `<header class="site-header">` страницы и `shared-chrome.js`, который строил второй. Итог — два набора навигации, `aria-current` на невидимых ссылках, дубли `id`.
- Хлебные крошки дублировались: статические `.st-crumbs` / `.crumbs` плюс сгенерированные shell’ом.
- Заголовки `h2` в учебных блоках несли `!important`-селекторы уровня 25 px и ломали иерархию (`h2.ops-legend-title` выглядел как `h1`).
- `<dl>` без `<dd>`-обёрток (`.def-list` из `<div>`), `<li>` без закрывающих тегов в архиве, `role="list"` с `<p>` внутри — axe давал `dlitem`, `list`, `aria-required-children`.
- Контраст подписей на цветных плашках навигации был ниже 4.5:1 (`#4E5658` на светло-сером, `#6B8EC8`/`#4ABEA0` с белым текстом).
- 110 инлайновых `style=` в разметке — цвет, отступы, высоты графиков.

### 3.2 CSS
- 221.2 KB в 5 legacy-файлах (`workspace.css`, `workspace-tokens.css`, `workspace-home.css`, `workspace-learning.css`, `catalog.css`), 1998 правил, 420 `!important`.
- Три конкурирующих палитры: `#f3f4f7` (холодный SaaS), `#f8f9fa`, терминальные тёмные вселенные; фиолетово-синий `#5b4bb0` как акцент направления.
- Стеклянные панели (`backdrop-filter`), тени-«подушки», hover-подъём карточек, декоративные иконки у каждого заголовка.
- Токены не покрывали состояния: цвета брались литералами прямо в компонентах.

### 3.3 JavaScript
- `shared-chrome.js` + `site.js` + `workspace.js` строили хром в три слоя; `workspace.js` падал на страницах, где нет `.st-topbar` внутри контента.
- `home-activity.js` содержал канбан с drag-and-drop, к которому не было разметки на странице; фильтры и «лента» жили в разных состояниях.
- `stands.js` принудительно ставил тёмную тему на каждой странице вселенной, из-за чего иконка темы в шапке врала.
- Мёртвые ссылки: `admin.js` генерировал `<link>` на удалённые css, `build-office.js` — на `workspace*.css`, `sw.js` кэшировал 10 несуществующих файлов.

### 3.4 Адаптивность
- Горизонтальная прокрутка на 360 px: статья о практико-ориентированном обучении (длинное слово «Практикоориентированное» в `h1` без переносов), кейс киберспорта (широкая панель статистики), таблицы стендов.
- Сетки 3×N одинаковых карточек на всех экранах — «три колонки всегда».
- Цели меньше 24 px: чипы фильтров ленты, ссылки-«этапы» в стендах.

### 3.5 Данные и честность
- Блок «Сайт развивается итерациями» — статический текст с цифрами, которые никто не проверял.
- Полка чтения собиралась из `localStorage`, а не из манифестов публикаций.
- Каталог проектов не имел поиска и состояния «ничего не найдено».

## 4. Что сделано

### 4.1 Один слой оболочки
- `assets/shell.js` — единственный источник шапки, подвала, меню, поиска, оглавления, переключателя темы и кнопки «наверх».
- `body.ui-ready`, `html[data-ui-ready]`, `body[data-area]`, `#ui-drawer`, `#ui-toc`, `dialog.ui-search`, `.ui-subbar` (строится из навигации вселенной), `.ui-tabbar` (мобильный).
- Дубли хлебных крошек удалены, `.st-topbar` читается из `document`, а не из контента.

### 4.2 Один слой токенов
- `tokens.css` (12.6 KB): бумага `#f6f2e9`, поверхности, чернила, глина `#a8391d`, семантические пары, шкала 11/12/13/14/17/18/20/25/31/39/49/62, шаг 4–80, радиусы 8/16/24, рельс 244 px.
- `base.css` (25.1 KB) — оболочка, формы, кнопки, таблицы, `:focus-visible`.
- `pages.css` (52.8 KB) — главная, каталоги, редакционные страницы, статические страницы, кейсы, лента.
- `course.css` (22.1 KB) — вселенные: `[data-ws-*]`, `.ops-*`, `.office-*`, `.lab-*`, `.st-*`.
- Legacy-файлы удалены, `!important` осталось два (`[hidden]`).

### 4.3 Семантика и доступность
- По одному `<main>` и одному `<h1>` на странице, `<time datetime>` в подвале, `<dl>` там, где пары «термин — значение».
- `:focus-visible` на всех интерактивных элементах, видимый skip-link, `aria-current="page"` только на активном пункте, `aria-expanded` у меню и фильтров.
- Контраст: текст на бумаге 16.03:1, вторичный 10.45:1, приглушённый 6.32:1, акцент 5.75:1; семантические пары 4.93–6.81:1 (таблица — в `DESIGN_SYSTEM.md`).
- 0 инлайновых `style=`; графики и полосы получают значения через `data-*` и CSS.
- axe: 0 serious/critical на 19 страницах в светлой и тёмной темах; Lighthouse a11y = 100.

### 4.4 Живые данные вместо декораций
- `feed.js`: GitHub API, окно 30 дней, `per_page=100`, до 7 карточек с хэштегами `#frontend #design #content #fix`, статусами, временем, каскадным появлением; график 14 дней; кэш `sessionStorage` на 15 минут; честный `—` и ссылка на историю при недоступности API.
- `home-reading.js`: полка из `blog/posts.json` и `articles/posts.json`, валидация `status: "published"`, безопасный `file`, форматы дат, фильтры «всё / заметки / статьи».
- `catalog.js`: поиск по строкам каталога, состояние «ничего не найдено», наблюдение за динамическими строками.

### 4.5 Адаптивность
- 360 px — одна колонка, таббар, выдвижное меню; 768 px — две колонки; 1024 px+ — полная сетка с рельсом оглавления.
- Горизонтальная прокрутка: 0 случаев на 15 маршрутах × 4 ширины (включая статью и кейс).
- Минимальная цель 28 px для кнопок и навигации, текстовые ссылки в абзацах остаются инлайн.

### 4.6 Честная уборка
- Удалены: `workspace*.css`, `catalog.css`, `shared-chrome.js`, `site.js`, `home-activity.js`, `workspace.js`, `i18n.js`, шрифты Manrope.
- Удалена внутренняя служебная страница `agent-plan.html` (план работ — в `AGENT_PLAN.md`), из sitemap и поискового индекса убрана.
- `projects/glossary.html` превращён в честный редирект на единый словарь (noindex + canonical + `meta refresh`).
- `assets/offline.html` переведён на те же токены, без собственного `<style>` и системного шрифта.

## 6. Ограничения

- Песочница не имеет доступа к `api.github.com`: лента в скриншотах показывает честное состояние «история недоступна». В браузере пользователя и на GitHub Pages данные приходят.
- В headless-Chromium нет цветных эмодзи: символы в скриншотах могут выглядеть квадратами. Это шрифт окружения, а не разметка.
- Lighthouse-оценки сняты на локальном gzip-сервере (`/tmp/serve.js`, вне репозитория); GitHub Pages отдаёт brotli — реальные значения не ниже.
