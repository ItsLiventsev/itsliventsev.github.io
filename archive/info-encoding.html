Информация. Кодирование

текст структурирован и оптимизирован с помощью ИИ

1. Что такое информация?

Информация (от лат. informatio — разъяснение, изложение) — это сведения об окружающем мире и протекающих в нем процессах, которые воспринимаются живыми организмами, электронными машинами и другими системами.

Ключевые свойства информации:
Объективность
Достоверность
Актуальность
Понятность
Полнота

Для специалистов по ремонту: недостоверная информация (искаженный сигнал из-за плохого контакта) приводит к сбоям в работе электронного устройства.

2. Кодирование информации

Кодирование — процесс преобразования информации из одной формы представления в другую, удобную для хранения, передачи или обработки.

Декодирование — обратный процесс преобразования закодированной информации в исходную форму.

Светофор
Красный = «Стой!», Зеленый = «Иди!»
Азбука Морзе
Точки и тире = буквы
Дорожные знаки
Фигуры и символы = правила

3. Двоичное кодирование

Практически все современные электронные приборы являются цифровыми. Они работают с дискретными сигналами, используя двоичное кодирование.

Почему двоичная система?
  • • Элементы электроники (транзисторы) проще всего находятся в двух состояниях
  • • Есть напряжение / Нет напряжения
  • • Ток течет / Ток не течет
  • • Магнитное поле есть / Нет поля
Соответствие
  • • 1 — есть сигнал (истина, да, высокий уровень)
  • • 0 — нет сигнала (ложь, нет, низкий уровень)
Бит (от англ. binary digit — двоичная цифра) — минимальная единица измерения количества информации и наименьшая единица представления данных в компьютере.

4. Единицы измерения информации

Единица Размер Чему равна
1 байт 8 бит Минимальная адресуемая единица памяти
1 Килобайт (КБ) 2¹⁰ байт 1024 байта
1 Мегабайт (МБ) 2²⁰ байт 1024 КБ
1 Гигабайт (ГБ) 2³⁰ байт 1024 МБ
1 Терабайт (ТБ) 2⁴⁰ байт 1024 ГБ

Важно: производители жестких дисков используют десятичную систему (1 КБ = 1000 байт), но в программировании — двоичную (1 КБ = 1024 байта). Поэтому реальная емкость диска меньше заявленной.

5. Как кодируется разная информация?

А) Числовая информация

Числа хранятся в двоичном виде. Существуют специальные форматы для целых и вещественных чисел, положительных и отрицательных.

Пример: 5₁₀ = 101₂
Б) Текстовая информация

Каждому символу присваивается уникальный двоичный код. Стандарт ASCII использует 7 бит (128 символов), расширенная — 1 байт (256 символов).

A = 65 (01000001), a = 97
В) Графическая информация

Изображение состоит из пикселей. Каждый пиксель имеет цвет, который кодируется числом.

  • • Черно-белое: 1 бит на пиксель (0 – белый, 1 – черный)
  • • Цветное (RGB): 3 байта на пиксель (Red, Green, Blue от 0 до 255)
Г) Звуковая информация

Звук — аналоговый сигнал. Для цифровой обработки производится дискретизация и квантование.

  • • Дискретизация — измерение амплитуды через равные промежутки времени (частота дискретизации, Гц)
  • • Квантование — присвоение каждому значению определенного уровня (глубина кодирования, бит)

>Ситуационная задача-квест: «Диагностика: Шифр неисправности»

Легенда: Вы — команда инженеров-электронщиков. К вам поступил ПЛК от промышленного станка. Перед поломкой ПЛК должен был вывести код ошибки, но индикатор показывает лишь беспорядочные двоичные последовательности.

Задача: Расшифровать код ошибки и определить неисправный блок.

Дамп памяти (расшифровать 4 символа):
  • • Символ 1: 100 1001 (двоичный → ASCII)
  • • Символ 2: 0x45 (hex → decimal → ASCII)
  • • Символ 3: 51 (decimal → ASCII)
  • • Символ 4: 0100 0010 (двоичный → ASCII)

Формат ответа: Код ошибки IE-XY, где X — буква (функциональный блок), Y — цифра (тип неисправности).
