Операция «Миграция»#

⚙️ текст структурирован и оптимизирован с помощью ИИ

Создание гибридной ИТ-экосистемы в компании «ВекторТех». Стратегический проект по обеспечению технологического суверенитета с интеграцией Windows Server и ALT Linux.

📋 Контекст ситуации

Компания: «ВекторТех» (развитие технологий для умных городов)

Ваша роль: Ведущий системный администратор (Senior SysAdmin) Алексей

Текущая инфраструктура:

  • 50 компьютеров под Windows 10/11
  • 5 физических серверов (старый парк)
  • Файловый NAS
  • Сети в режиме рабочих групп (хаос, нет централизованного управления)

Цель: Построить отказоустойчивую, безопасную и управляемую ИТ-инфраструктуру с интеграцией Windows Server и ALT Linux.

📅 Неделя 1: Планирование и расчеты

Задача 1.1: Расчет бюджета и планирование сети

  • Спроектировать логическую сеть с разделением на подсети: управление (серверы), пользователи (офис), гости (Wi-Fi), инженеры (лаборатория)
  • Рассчитать стоимость оборудования (2 новых сервера для виртуализации, коммутаторы L3, ИБП)
  • Рассчитать лицензии Windows Server 2022 Standard и CAL
  • Подготовить таблицу Excel с двумя вариантами (премиум и эконом)

Недели 2-3: Развертывание базовой инфраструктуры

Задача 2.1: Windows Server 2022
  • • Установить ОС с ролью AD DS
  • • Создать лес домена vector.tech
  • • Создать структуру OU
  • • Настроить группы и пользователей
  • • Настроить GPO (пароли, USB, принтеры)
Задача 2.2: ALT Server
  • • Установить ALT WorkStation/Server
  • • Обновить систему
  • • Установить пакеты: dhcp-server, bind, chrony
  • • Настроить статический IP

📅 Неделя 4: Организация сетевых сервисов и безопасности

Задача 3.1: DHCP и DNS на ALT Server
  • • Настроить DHCP с динамическими пулами для пользовательской и гостевой подсети
  • • Настроить резервации для критичных устройств
  • • Настроить DNS (BIND) с прямой зоной vector.tech
  • • Настроить условную пересылку на публичные DNS
Задача 3.2: Сетевая безопасность
  • • Windows Server: Remote Access Service (RAS) с VPN (SSTP/IKEv2)
  • • Маршрутизатор: правила firewall, изоляция гостевой сети
  • • ALT Server: firewalld (разрешить только DNS и DHCP)

📅 Неделя 5: Ввод в эксплуатацию и мониторинг

Задача 4.1: Подключение рабочих станций
  • • Присоединить 2-3 тестовые Windows 10/11 к домену vector.tech
  • • Проверить вход под a.ivanov
  • • Установить ALT Workstation в лаборатории
  • • Настроить DHCP и DNS
Задача 4.2: Сбор данных и анализ
  • • Активировать Audit Policy на Windows Server
  • • Performance Monitor: загрузка ЦП и памяти за 24 часа
  • • Создать отчет (PowerPoint): схема сети, диаграммы, статистика
