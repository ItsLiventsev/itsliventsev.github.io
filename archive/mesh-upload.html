Загрузка сценариев в МЭШ

текст структурирован и оптимизирован с помощью ИИ

Пошаговая инструкция по загрузке сценариев уроков в библиотеку Московской электронной школы (МЭШ).

!Важно

Для работы с загрузкой сценариев используйте роль «Методист СПО». Проверьте, что выбрали её в всплывающем окне профиля на сайте библиотеки — uchebnik.mos.ru/main

1. Добавление нового материала

На главной странице библиотеки выберите кнопку «+ Добавить материал». Для загрузки сценариев используется тип материала — «Сценарий урока».

2. Свойства урока

Открывается окно «Свойство урока» в новой вкладке браузера. Заполняйте исключительно по презентации/сценарию:

Название
Название предмета и темы из презентации
Описание (цель)
Цель из презентации (до 255 символов)
Профессия/специальность
По сценарию, без шифра в названии
Квалификация
В соответствии с сценарием/учебным планом
Курс
Загружаем всё по первому курсу («1»)
Дисциплина
очень внимательно: название — без шифра

3. Загрузка обложки

В качестве обложки используйте титульный лист из презентации — сделайте качественный скриншот или сохраните титульный слайд как PNG/JPEG.

4. Работа в конструкторе

Нажмите кнопку «Создать сценарий». В выборе шаблона выберите «Без шаблона».

Структура конструктора:
  • • Левая панель: работа с фрагментами и структурой урока
  • • Центральная часть: редактирование и добавление материала
  • • Правая панель: настройка свойств добавленного материала

В нашей работе используется только слайд для интерактивной доски и слайд для устройства учителя.

5. Добавление фрагментов

Фрагмент сценария урока — структурная единица сценария, представленная отдельной горизонтальной линейкой слайдов. Под каждый вид оборудования разрабатывается отдельный слайд.

Для добавления фрагмента нажмите на кнопку «+ Добавить фрагмент».

6. Перенос презентации из PowerPoint в МЭШ

Принцип:

Оформление презентации берем из PowerPoint (всё, кроме текста) — загружаем как изображение и используем как «фон» слайда. Текст добавляем отдельными блоками.

Шаг 1: Подготовка фона
  1. 1. Откройте презентацию, найдите титульный лист
  2. 2. Удалите все блоки текста на слайде (предварительно сохраните копию с текстом)
  3. 3. Сохраните слайд как рисунок (PNG или JPEG) — «Только этот»
Шаг 2: Загрузка фона в МЭШ
  1. 1. В меню выберите «Медиа» → «Изображение» → «Загрузить своё»
  2. 2. Загрузите файл с компьютера
  3. 3. Нажмите по изображению ЛКМ → справа найдите «Сделать фоном» → поставьте галочку
Шаг 3: Добавление текста
  1. 1. В меню выберите «Текст» → «Пользовательский текст»
  2. 2. Подведите блок на необходимое место и добавьте текст
  3. 3. Требования: размер шрифта для заголовка — 24-54 пт (жирный), для текстовых блоков — 22-36 пт
  4. 4. Для выбора цвета используйте корпоративный цвет колледжа: #0070c0

7. Комментарии для преподавателя

Для ввода комментария (подстрочника) для преподавателей перейдите на второй вариант слайда (устройство учителя). Этот слайд будет виден только преподавателю. Разместите на нём текст из комментария в презентации.

8. Название фрагментов и время

Название фрагмента: прописывайте название темы или раздела.

Время на слайд: прописывайте в соответствии с комментарием из презентации.
