#Урок 1: «Охота на невидимок»

1 акад. час | до 10 баллов | Индивидуальный

Ситуация: На компьютере пользователя интернет «тормозит», хотя скорость по тарифу 100 Мбит/с. Браузер закрыт, но трафик куда-то уходит.

Этап 1: Разведка (15 мин, 3 балла)
  1. 1. Откройте Task Manager (Ctrl+Shift+Esc)
  2. 2. Перейдите на вкладку «Процессы» → добавьте столбец «Сеть»
  3. 3. Отсортируйте по потреблению сети
  4. 4. Найдите ТОП-5 процессов-потребителей
  5. 5. Для каждого запишите: имя, PID, объём трафика
Этап 2: Глубокий анализ (20 мин, 5 баллов)
  1. 1. Откройте Resource Monitor (resmon.exe)
  2. 2. Перейдите на вкладку Network
  3. 3. Изучите: Processes with Network Activity, Network Activity, TCP Connections, Listening Ports
  4. 4. Найдите процесс с самым высоким Total (B/sec)
  5. 5. Создайте мини-досье на процесс

#Урок 2: «Следы в сети»

1 акад. час | до 12 баллов | Индивидуальный

Ситуация: Администратор заметил подозрительные соединения с неизвестными IP-адресами из разных стран.

Этап 1: Командная строка — ваш друг (25 мин, 6 баллов)
шаг 1: Обучение с ИИ

Спросите у ИИ: «Объясни команду 'netstat -ano' в Windows: что означает каждый ключ (-a, -n, -o), как читать вывод, что означают столбцы Proto, Local Address, Foreign Address, State, PID?»

шаг 2: Практика
  1. • Откройте CMD от имени администратора
  2. • Выполните: netstat -ano > C:\netstat_full.txt
  3. • Выполните: netstat -ano | findstr ESTABLISHED > C:\netstat_established.txt
шаг 3: Анализ

Откройте netstat_established.txt и найдите 5 разных внешних IP-адресов и соответствующие PID процессов.

шаг 4: Идентификация

Для каждого PID выполните: tasklist | findstr «[PID]»

Этап 2: Географический анализ (15 мин, 4 балла)
  • • Спросите у ИИ: «Как узнать географическое расположение IP-адреса?»
  • • Проверьте 5 IP-адресов через: https://www.ip2location.com/ или who.is/
  • • Добавьте в таблицу: Страна, Город, Организация (ISP/Company), ASN
  • • Оцените риски: Низкий (Google, Microsoft), Средний (CDN), Высокий (подозрительные)

#Урок 3: «Командное сражение: Пожиратели трафика»

1 акад. час | до 15 баллов | Групповая работа

Новый формат: Сессионные залы VK. 11 человек → 2 команды (Blue Team и Red Team).

Миссия для обеих команд:

Ваша компания обнаружила, что за последний месяц расход трафика вырос на 200%. Руководство требует найти причины и предложить решения.

1. Диагностика (10 мин): Каждый участник запускает Task Manager → Performance → Ethernet, Resource Monitor → Network, netstat -ano | findstr ESTABLISHED
2. Централизация (10 мин): Создайте общую Google Таблицу с листами: ПРОЦЕССЫ, СОЕДИНЕНИЯ, СТАТИСТИКА
3. Анализ (10 мин): Ответьте на вопросы: Какой процесс чаще всего встречается? Какие страны доминируют? Есть ли подозрительные соединения?
4. Отчёт (10 мин): Презентация на 5 слайдов: Команда, Диагностика, География, Проблемы и риски, Рекомендации

#Урок 4: «Укротитель обновлений»

1 акад. час | до 14 баллов | Индивидуальный

Ситуация: Windows Update загружает обновления в рабочее время, парализуя работу. Облачные сервисы синхронизируются без разрешения.

Этап 1: Анатомия автообновлений (25 мин, 7 баллов)
шаг 1: Исследование служб
  1. • Откройте services.msc (Win+R → services.msc)
  2. • Найдите службы, связанные с обновлениями: wuauserv, UsoSvc, WaaSMedicSvc, DoSvc
  3. • Создайте таблицу: Служба, Display Name, Status, Startup Type, Dependencies
шаг 2: Групповые политики
  1. • Откройте gpedit.msc (Win+R)
  2. • Путь: Computer Configuration → Administrative Templates → Windows Components → Windows Update
  3. • Настройте: Configure Automatic Updates → «2 - Notify for download and auto install»
  4. • Active Hours → установите рабочее время (08:00-20:00)
Этап 2: Облачные синхронизации (15 мин, 5 баллов)
  • • Откройте Task Manager → вкладка Startup
  • • Найдите облачные клиенты: OneDrive, Google Drive, Dropbox, Yandex.Disk
  • • Для каждого настройте ограничение скорости синхронизации
  • • Выберите только важные папки для синхронизации
  • • Создайте чек-лист оптимизации
