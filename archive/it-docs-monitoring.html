IT-документооборот и мониторинг

текст структурирован и оптимизирован с помощью ИИ

Комплексная практическая задача для оператора IT-отдела компании «IT-Ресурс» (100+ рабочих мест). Выполняется на ПК под управлением Windows 10/11 с использованием стандартного и свободного ПО.

1 База данных IT-оборудования

Создать БД «IT_Inventory» в MS Access или LibreOffice Base. Таблица Оборудование должна содержать поля:

ID (PK, автоинкремент) Тип Модель Инв. номер MAC / IP Местонахождение Статус

Задача: ввести 15 записей, создать форму для ввода, запрос для кабинета 301 и отчет «Список по типам».

2 Мониторинг сетевой инфраструктуры

  • • ipconfig /all → сохранить IPv4, MAC, шлюз, DNS.
  • • tracert 8.8.8.8 → определить количество хопов.
  • • ping шлюза и yandex.ru → зафиксировать среднее время отклика.
  • • netstat -an | findstr :80 → проверка открытых портов HTTP.
  • • Монитор ресурсов → скриншоты загрузки сети и активных процессов.

Дополнительно: построить логическую схему сети (ПК, коммутаторы, шлюз, сервер, принтер, интернет) в Draw.io или Visio с IP-адресами из диапазона 192.168.10.0/24.

3 Работа со сканированными документами

Распознать текст (OCR) из JPEG-скана договора с помощью Adobe Acrobat Reader DC или FineReader Online. Сохранить в DOCX. Применить стили заголовков, создать автоматическое оглавление, колонтитулы, гиперссылку и добавить 3 комментария в режиме рецензирования.

4 Анализ табличных данных (Excel)

Создать таблицу «Учет заявок» (30-40 строк). Применить «Умную таблицу» (Ctrl+T).

Формулы: СУММЕСЛИ (время по отделу «Бухгалтерия»), СРЗНАЧЕСЛИ (среднее время сетевых проблем).
Визуализация: Условное форматирование (красный > 8 часов), сводная таблица, круговая диаграмма, гистограмма и график динамики.

5-6 Презентация и простой IT-сайт

PowerPoint (8-10 слайдов): Титульный, содержание с гиперссылками, статистика, схема сети, планы, SmartArt, резюме со звуком. Настроить слайд-шоу (15 сек, переходы, сохранение в PPTX и PDF).

Одностраничный сайт (HTML/CSS или конструктор): Заголовок H1, описание, таблица дежурств, изображение схемы сети, список полезных ссылок, контактная форма. Требуется базовая CSS-стилизация.
